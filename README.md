# Harrison Ndungu Portfolio — GitHub Pages

A static HTML, CSS and JavaScript portfolio prepared for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/` — add your personal images and CV here
- `.nojekyll` — disables Jekyll processing

## Before publishing
1. Add your own files to `assets/` using these exact names:
   - `profile.jpg` — profile photograph
   - `cv.pdf` — current CV
2. Optional: replace the CSS project-art placeholders with your own project screenshots.
3. Check that your email address in the FormSubmit form is correct.
4. Submit the contact form once and follow FormSubmit's email activation instructions.

## Publish with GitHub Pages
1. Create or open the public repository `harrison-ndungu`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment to complete. GitHub will display the published URL in the Pages settings.

Expected project URL for account `njoroo-tech`:
https://njoroo-tech.github.io/harrison-ndungu/

## Important
GitHub Pages hosts static files only. It does not run PHP or MySQL. The contact form in this starter uses FormSubmit, a third-party service, and needs email activation before it can deliver messages.
